# VAPT AI Platform

AI-assisted vulnerability assessment and reconnaissance platform built using FastAPI.

## Features

- Recon automation
- Async scan execution
- Concurrent scanning
- Risk scoring
- AI summaries
- Security recommendations
- Dashboard UI
- Analytics APIs
- Authentication
- SQLite database
- Markdown & JSON reports
- Caching layer

## Tech Stack

- Python
- FastAPI
- SQLite
- Jinja2
- AsyncIO

## Run Project

```bash
uvicorn main:app --reload
```
